# 叙事设计文档 (Narrative Design Document)
## 《ECHO：最后一次呼吸》(ECHO: The Last Resonance)

**版本**: v2.0
**日期**: 2025-12-31
**类型**: 3D 写实叙事节奏游戏
**预计游戏时长**: 4-6小时

---

> **核心标语**: "世界并没有死，它只是屏住了呼吸。而你，是它的肺。"

---

## 第一部分：世界观设定

### 1.1 "大石化" (The Great Calcification)

**事件定义**: 并非病毒或灾难，而是一种物理维度的**"时间冻结"**。时间失去了流动性，世界陷入了永恒的静止。

**发生时间**: 无人知晓。可能是昨天，可能是一万年前。在没有时间的世界里，"多久"这个概念毫无意义。

#### 各区域石化表现

| 区域 | 石化表现 | 视觉关键词 |
|------|---------|-----------|
| **峡谷** | 灰白色的裂谷，风声都被冻结。石花保持半开状态 | 极简、寂静、灰度 |
| **森林** | 每片树叶变成锋利灰岩，悬停在飘落的半途 | 悬浮、锐利、压迫感 |
| **海洋** | 海水凝固成琥珀色胶状物，波浪定格在几十米高空 | 琥珀、透明、巨大 |
| **冰原** | 极北之地，永恒的白与黑。巨鲸搁浅 | 史诗、苍凉、神圣 |

#### 石化生物特征
- 没有死亡，只有凝固
- 人类和动物保持最后一秒的动作
- 眼神中依然残留着情感
- 不是尸体，是等待苏醒的雕像

### 1.2 "静默" (The Silence)

**定义**: "大石化"的元凶/自然现象。它不是敌人，而是宇宙熵增的具象化。

**表现形式**:
- 视觉：黑色的、吸光的油泥/虚空，缓慢蔓延
- 听觉：绝对的寂静，吞噬一切声音
- 触觉：接触后感到**刺骨的寒冷**和**无尽的疲惫**

**行为模式**:
1. 玩家演奏时 → 静默后退，世界复苏
2. 玩家停止演奏 → 静默上涨，视野收窄，最终石化
3. 玩家演奏失误 → 静默产生"涟漪"，短暂侵蚀复苏区域

### 1.3 "调律者" (The Tuner)

**设定**: 世界上最后一个拥有"流动时间"的人。

**存在意义**:
- 你不是英雄，你是**"世界的肺"**
- 你的"呼吸"（演奏）维持着局部时间的流动
- 停止呼吸 = 世界的死亡 = 你的石化

| 组件 | 功能 | 视觉表现 |
|------|------|---------|

| **黄铜风管** | 将生命力转化为声波 | 演奏时发光，蒸汽喷射 |
| **肩部支架** | 外骨骼结构，分担重量 | 工业朋克风格，铆钉装饰 |
| **背部仪表** | 显示"生命力"（即血量） | 指针震动，玻璃罩内有气泡 |
| **呼吸面罩** | 连接主体，过滤"静默"空气 | 铜质，有呼吸阀门声效 |

### 2.2 反派：熵 (The Entropy)

**视觉设计**:
- 不是生物，是**"存在的缺失"**
- 表现为黑色油泥/虚空
- 光线无法穿透，声音无法传递
- 边缘有类似热浪的扭曲效果

**行为 AI**:
```
状态机:
├─ 潜伏状态 (玩家演奏中)
│   └─ 缓慢收缩，距离玩家保持安全距离
├─ 侵蚀状态 (玩家停止演奏)
│   └─ 每秒向玩家方向推进 X 单位
├─ 应激状态 (玩家失误)
│   └─ 产生扩散波纹，临时吞噬部分复苏区域
└─ 胜利状态 (完全包围玩家)
    └─ 玩家石化，Game Over
```

## 第三部分：详细关卡设计

### 序章：第一口气 (The First Breath)

**场景描述**: 灰白色峡谷。死寂无声，连风声都没有。你从一个石洞中醒来。

**时长**: 约 5-10 分钟

**叙事目标**: 
- 建立世界观
- 教学核心机制
- 传递"第一次希望"的情感

#### 节拍设计

| 时间点 | 事件 | 玩家操作 | 反馈 |
|:------:|------|---------|------|
| 0:00 | 黑屏，听到心跳声 | 无 | 心跳声是唯一的声音 |
| 0:30 | 画面淡入，玩家在石洞中 | 移动教学 | 脚步声沉重、回响 |
| 1:00 | 走出洞口，看到灰色峡谷 | 观察环境 | 没有任何动态，绝对静止 |
| 2:00 | 发现一朵石化的花 | 接近，UI提示按键 | 花开始微颤（判定预警） |
| 2:30 | **第一次演奏** | 按下按键 | **"Ping——"** |

#### "第一口气"视觉序列

```
1. 按键瞬间
   └─ 屏幕轻微白闪
   
2. 冲击波扩散 (0.5s)
   └─ 以花为中心的圆形波纹
   └─ 波纹带动空气粒子
   
3. 石壳崩裂 (1s)
   └─ 花的灰色外壳碎裂
   └─ 碎片飞散 (Niagara)
   └─ 露出鲜嫩粉色花瓣
   
4. 生命恢复 (2s)
   └─ 花瓣开始摇曳 (WPO)
   └─ 颜色从中心向外扩散
   └─ Lumen：微弱粉色反光照亮峡谷
   
5. 情感高潮
   └─ 镜头拉远，展示灰色峡谷中唯一的粉色
   └─ 这是世界的第一次呼吸
```

### 第一章：森林的记忆 (Memory of the Forest)

**场景描述**: 古老的森林，所有树木都变成了灰岩。树叶悬浮在空中，保持飘落的姿态。

**时长**: 约 45-60 分钟

**核心机制**: "自然判定" - 通过观察环境获取节拍提示

#### 子区域规划

| 区域 | 环境特征 | 判定物体 | 情感基调 |
|------|---------|---------|---------|
| **林缘** | 稀疏的石树，阳光穿透 | 悬浮雨滴 | 希望、好奇 |
| **深林** | 密集树冠，几乎无光 | 发光蘑菇 | 紧张、谨慎 |
| **古树** | 巨型神木，根系盘绕 | 古树心跳 | 敬畏、虔诚 |

#### 机制详解：自然判定

**悬浮雨滴判定**:
```
预警 (2拍前):
  └─ 雨滴开始微颤，发出细微光芒

准备 (1拍前):
  └─ 雨滴加速下落开始

判定 (触地瞬间):
  └─ 玩家按键
  └─ Perfect: 雨滴化为真实水花，滋润土地
  └─ Miss: 雨滴碎成石屑，土地龟裂
```

**发光蘑菇判定**:
```
深林中唯一的光源
蘑菇按节奏闪烁
  └─ 暗 → 亮 = 预警
  └─ 最亮瞬间 = 判定点
  └─ Perfect: 蘑菇释放孢子光云
  └─ Miss: 蘑菇熄灭，区域变黑
```

#### 第一章 BOSS：古树苏醒

**流程**:
1. 玩家到达古树根部
2. 发现古树胸口有一个"心脏"状的凹陷
3. 需要持续演奏"心跳节奏" (长按+点击组合)
4. 古树逐渐复苏:
   - 根系开始伸展
   - 树皮龟裂，露出翠绿
   - 树冠抖落灰尘
   - 阳光穿透，God Rays 效果

**视觉高潮**:
```
古树完全苏醒的瞬间:
1. 巨大的灰尘云 (Niagara 烟雾)
2. 阳光穿透树冠 (丁达尔效应)
3. 周围百米内的植物瞬间复苏
4. 鸟类从石化中苏醒，飞向天空
5. 玩家背后的"共鸣肺"喷出大量白色蒸汽
```

### 第二章：凝固之海 (The Resin Sea)

**场景描述**: 海边悬崖。巨大的海浪凝固在几十米的高空，像琥珀一样透明。

**时长**: 约 60-75 分钟

**核心机制**: "长按连音" - 保持弦乐演奏，控制海水融化

#### 子区域规划

| 区域 | 环境特征 | 核心玩法 | 情感基调 |
|------|---------|---------|---------|
| **海岸线** | 凝固的波浪刚触及陆地 | 学习长按机制 | 震撼、敬畏 |
| **浪管隧道** | 进入凝固浪管内部 | 滑行 + 节奏 | 刺激、恐惧 |
| **深海坟场** | 海底沉船与生物 | 探索解谜 | 悲伤、反思 |

#### 机制详解：长按连音

**基础长按**:
```
按住按键 → 持续演奏弦乐
  └─ 海水开始融化、流动
  └─ 释放按键 → 海水即刻再次凝固

危险:
  └─ 如果在浪管中释放，会被凝固的海水困住
  └─ 需要重新演奏才能"解冻"自己
```

**滑行节奏**:
```
在融化的浪管中滑行时:
  └─ 保持长按 = 保持海水流动
  └─ 遇到障碍物 = 需要额外点击
  └─ 节奏失误 = 海水半凝固，速度下降
```

#### 恐怖元素：凝固的亡者

**视觉描述**:
- 透过琥珀色的"海水"，可以看到:
  - 巨大的鲸鱼，永远张开的嘴
  - 成群的鱼，保持游动的姿态
  - 人类的潜水艇，舷窗内有凝固的人影
  - 一只手，从"海水"中伸出，仿佛在求救

**叙事意义**: 
- 这些不是尸体，他们还活着
- 他们在等待复苏
- 但你无法拯救所有人

### 终章：鲸落与新生 (The Whale's Song)

**场景描述**: 极北冰原。一只体型如山岳的座头鲸搁浅在这里，半截身子已经石化。

**时长**: 约 30-45 分钟

**核心设计**: 没有敌人，敌人是自己的疲惫

#### 环境设计

```
场景布局:

        [北极星]
           ☆
           |
    [极光 - Aurora Borealis]
           |
   ╔═══════════════════════╗
   ║                       ║
   ║    [座头鲸 - 山岳般] ║
   ║    ████████████████   ║
   ║    石化部分██████████  ║
   ║                       ║
   ║         (玩家)        ║
   ║           ▲           ║
   ╚═══════════════════════╝
        [冰原 - 无尽的白]
```

**鲸鱼设计**:
| 部位 | 状态 | 视觉特征 |
|------|------|---------|
| 尾部 | 完全石化 | 灰色，静止，有裂纹 |
| 腹部 | 半石化 | 灰白交界，缓慢"呼吸" |
| 头部 | 接近存活 | 眼睛闭着，有微弱光芒 |

#### 最终战机制

**Phase 1: 独奏 (Solo)**
- 玩家独自演奏
- 只有钢琴音色
- 谱面稀疏
- 血量开始缓慢下降

**Phase 2: 二重奏 (Duet)**
- 鲸鱼开始回应
- 加入大提琴低音
- 谱面密度增加
- 血量下降速度加快

**Phase 3: 交响 (Symphony)**
- 世界的记忆觉醒
- 森林、海洋的声音加入
- 宏大的交响乐
- 谱面高密度
- 血量快速下降
- 画面开始模糊（视力下降）

**Phase 4: 最后一息 (The Last Breath)**
```
血量归零
  └─ 玩家动作变慢
  └─ 画面几乎全黑
  └─ 但手指仍在键盘上
  └─ 最后一个音符...
  
主角倒下
  └─ 摔倒在雪地
  └─ "共鸣肺"的蒸汽停止
  └─ 一切归于寂静...

但是——

鲸鱼睁开眼睛
  └─ 巨大的眼球，有着星空般的瞳孔
  └─ 目光温柔，看向倒下的玩家
```

#### 结局动画 (约 3 分钟)

```
1. [0:00] 鲸鱼长鸣
   └─ 一声贯穿天地的鸣叫
   └─ 声波可视化，扩散成金色波纹
   └─ 冰原开始震动

2. [0:30] 连锁苏醒
   └─ 波纹扫过冰原，冰层开始碎裂
   └─ 被困在冰中的生物开始动弹
   └─ 远处的海洋开始流动

3. [1:00] 全球复苏
   └─ 镜头拉升至太空
   └─ 地球被灰色覆盖
   └─ 绿色波纹从极北扩散
   └─ 每经过一处，颜色恢复
   └─ 风开始吹，云开始动

4. [1:45] 世界重生
   └─ 快速蒙太奇:
       - 森林中的古树完全苏醒
       - 海洋中的鲸鱼群开始歌唱
       - 城市中的人们解除石化
       - 孩子们开始奔跑

5. [2:30] 永恒的雕像
   └─ 镜头回到极北
   └─ 鲸鱼已完全复苏，游向深海
   └─ 在它曾经搁浅的地方
   └─ 一座雕像矗立在雪中
   └─ 那是埃利安，带着微笑
   └─ "共鸣肺"化作了石头，但形态依然
   └─ 雪花飘落，覆盖雕像

6. [3:00] 尾声
   └─ 黑屏
   └─ 远处传来孩子的笑声
   └─ 以及，鲸鱼的歌唱
   └─ "ECHO: The Last Resonance"
   └─ 制作名单
```

### 4.2 动态音乐系统

```
音轨分层:
├─ Layer 0: 环境 (Ambience)
│   └─ 始终播放，低音量
├─ Layer 1: 节奏 (Rhythm)
│   └─ 玩家开始演奏时淡入
├─ Layer 2: 旋律 (Melody)
│   └─ 连续成功 > 4 次后淡入
├─ Layer 3: 高潮 (Climax)
│   └─ BOSS 战或叙事高潮时
└─ Layer 4: 惩罚 (Punishment)
    └─ 失误时，所有层增加 Low-Pass Filter
```
