# 关卡设计指南 (Level Design Guidelines)

**版本**: v2.0
**日期**: 2025-12-31
**基于**: Narrative_Design.md v2.0

---

> **设计哲学**: "关卡中的每一个物体都是潜在的乐器。关卡本身就是一张乐谱。"

---

## 1. 世界度量标准 (World Metrics)

### 1.1 玩家参数

| 参数 | 数值 | 说明 |
|------|:----:|------|
| 行走速度 | 600 uu/s | 沉重、疲惫的步伐 |
| 冲刺速度 | 1000 uu/s | 仅在特定场景可用 |
| 滑行速度 | 1500 uu/s | 海洋章节专用 |
| 摄像机高度 | 170 uu | 第一人称视平线 |
| 交互距离 | 300 uu | 可与物体交互的最大距离 |

### 1.2 节拍物体规范

| 类型 | 可见提前量 | 屏幕位置 | 视觉强度 |
|------|:---------:|---------|---------|
| 核心音符 | 2-4 拍 | 中央 50% | 高自发光 (>20) |
| 环境音符 | 1-2 拍 | 周边区域 | 中自发光 |
| 隐藏音符 | 无预警 | 任意 | 仅声音提示 |

## 2. 章节关卡规划

### 序章：第一口气 (The First Breath)

**时长**: 5-10 分钟
**音符密度**: 极低 (1/4 拍)
**核心教学**: 单次点击

```
场景流程:

[石洞入口] ──────▶ [峡谷小路] ──────▶ [石花位置]
    │                   │                   │
    ▼                   ▼                   ▼
 移动教学           观察环境            第一次演奏
```

**布局要点**:
- 线性路径，无分支
- 灰白色调，极简主义
- 石花是唯一的颜色焦点（即使是石化的灰色也要更亮）
- 天空无云，静止的光线

---

### 第一章：森林的记忆 (Memory of the Forest)

**时长**: 45-60 分钟
**音符密度**: 低→中 (1/2 → 1/1 拍)
**核心机制**: 环境判定（雨滴、蘑菇）

#### 区域1: 林缘 (Forest Edge)

```
布局:

    [天空 - 可见]
         │
    ░░░░░░░░░░░░░░   ← 稀疏树冠
    ║            ║
    ║  [悬浮雨滴] ║   ← 判定物体
    ║     ▼      ║
    ║   (玩家)   ║
    ║     ▲      ║
    ╚════════════╝
      [草地]
```

**设计规范**:
- 阳光可穿透，营造希望感
- 悬浮雨滴间隔 2-3 米
- 每 4 拍一个判定点
- 成功后草地生长动画

#### 区域2: 深林 (Deep Forest)

```
布局:

    [天空 - 不可见]
    ████████████████   ← 密集树冠
    ║              ║
    ║ 🍄    🍄    ║   ← 发光蘑菇
    ║      ▼      ║
    ║   (玩家)    ║
    ║  [黑暗区域] ║
    ╚══════════════╝
```

**设计规范**:
- 几乎无自然光
- 发光蘑菇是唯一光源
- 蘑菇按节奏闪烁（预警机制）
- 失误后蘑菇熄灭，造成恐惧

#### 区域3: 古树 (The Ancient Tree)

```
布局:

              [树冠]
           ╱        ╲
        ╱              ╲
      ╱    [God Rays]    ╲        ← 成功后出现
    ╱                      ╲
    │      [古树主干]      │      ← 巨型 (高度 50m+)
    │          ♥           │      ← 心脏位置 (判定中心)
    │                      │
    └──[根系]──(玩家)──[根系]──┘
```

**BOSS 战设计**:
- 需要持续演奏 30-60 秒
- 长按 + 点击组合
- 古树逐步苏醒的视觉阶段（根系 → 树干 → 树冠）

---

### 第二章：凝固之海 (The Resin Sea)

**时长**: 60-75 分钟
**音符密度**: 中→高
**核心机制**: 长按连音、滑行

#### 区域1: 海岸线 (The Shoreline)

```
侧视图:

    ╔════════════════════════════╗
    ║     [凝固的巨浪]           ║  ← 20-30m 高
    ║    ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓         ║
    ║   ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓        ║
    ║  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓       ║
    ╠═══════════════════════════╣
    ║  (玩家)  [海滩]            ║
    ╚════════════════════════════╝
```

**设计规范**:
- 浪尖透明，可看到内部冻结的生物
- 海水呈琥珀色
- 长按时浪尖开始融化滴落

#### 区域2: 浪管隧道 (Wave Tube)

```
玩家进入浪管后的视角:

    ╭────────────────────────────────╮
    │        [凝固海水壁]            │
    │  ╭──────────────────────────╮  │
    │  │                          │  │
    │  │      → (玩家滑行)        │  │
    │  │                          │  │
    │  ╰──────────────────────────╯  │
    │        [凝固海水底]            │
    ╰────────────────────────────────╯

    持续长按 = 隧道内壁保持流动
    释放 = 海水凝固，玩家减速/停止
```

**障碍设计**:
| 障碍类型 | 操作 | 失败后果 |
|---------|------|---------|
| 凝固碎片 | 额外点击 | 速度下降 |
| 分叉路口 | 方向键 | 走入死路 |
| 海洋生物 | 快速连点 | 被暂时困住 |

#### 区域3: 深海坟场 (Abyssal Graveyard)

**叙事区域** (非战斗):
- 玩家看到凝固在海水中的:
  - 古老的沉船
  - 人类潜水艇（舷窗内有人影）
  - 巨大的海洋生物骨架
- 无判定，纯探索和叙事
- 背景音乐变得压抑

---

### 终章：鲸落与新生 (The Whale's Song)

**时长**: 30-45 分钟
**音符密度**: 低→极高
**核心机制**: 生命值消耗、多阶段 BOSS

```
场景布局 (俯视图):

    ╔══════════════════════════════════════════╗
    ║                 [极光]                   ║
    ║                                          ║
    ║    ████████████████████████████████      ║
    ║    █                              █      ║  ← 座头鲸
    ║    █   [石化尾部]     [存活头部]  ◉ █    ║  ← ◉ = 眼睛
    ║    █                              █      ║
    ║    ████████████████████████████████      ║
    ║                                          ║
    ║              (玩家起始位置)              ║
    ╚══════════════════════════════════════════╝
```

**阶段设计**:

| 阶段 | 音乐 | 谱面密度 | HP消耗/秒 | 视觉效果 |
|:----:|------|:--------:|:---------:|---------|
| 1 | 钢琴独奏 | 1/4 拍 | 1% | 清晰 |
| 2 | +大提琴 | 1/2 拍 | 2% | 轻微模糊 |
| 3 | +管弦乐 | 1/1 拍 | 3% | 明显模糊 |
| 4 | 全交响 | 连续 | 5% | 几乎失明 |

## 4. 镜头语言

### 关键镜头设计

| 时刻 | 镜头类型 | 效果 |
|------|---------|------|
| 第一朵花绽放 | 慢放 + 拉远 | 震撼感 |
| 古树苏醒 | 仰视 + 环绕 | 敬畏感 |
| 进入浪管 | 跟随 + 晃动 | 刺激感 |
| 鲸鱼睁眼 | 特写 → 拉远 | 史诗感 |
| 地球复苏 | 太空视角 | 升华感 |
