## 1. 设计哲学

> "音乐不是配乐，音乐是游戏机制的核心。玩家不是在听音乐，玩家在*创造*音乐。"

ECHO 的音频系统必须实现：
1. **采样级同步**: 游戏事件与音频必须在毫秒级别同步
2. **动态分层**: 音乐根据玩家表现实时变化
3. **叙事融合**: 声音是世界观的一部分（静默 vs 共鸣）

```cpp
// ECHOAudioClockSubsystem

ClockSettings.TimeSignature.NumBeats = 4;      // 4/4 拍
```

## 3. 动态音乐系统

### 3.1 音轨分层架构

```
┌─────────────────────────────────────────────────────────────┐
│                    Master Output                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌────────────┐  ┌────────────┐  ┌────────────┐            │
│  │  Layer 0   │  │  Layer 1   │  │  Layer 2   │  ...       │
│  │ Ambience   │  │  Rhythm    │  │  Melody    │            │
│  │ (始终播放) │  │ (演奏时)   │  │ (连击>4)   │            │
│  └────────────┘  └────────────┘  └────────────┘            │
│        ▲               ▲               ▲                   │
│        │               │               │                   │
│  ┌─────┴───────────────┴───────────────┴─────┐             │
│  │          Submix: Music                     │             │
│  │  [Low-Pass Filter] [Distortion] [Reverb]  │             │
│  └───────────────────────────────────────────┘             │
│                          ▲                                  │
│                          │                                  │
│                 游戏状态 → 参数控制                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 分层触发规则

| 层级 | 名称 | 触发条件 | 淡入时间 |
|:----:|------|---------|:--------:|
| 0 | Ambience | 始终播放 | - |
| 1 | Rhythm | 玩家开始演奏 | 0.5s |
| 2 | Melody | 连续成功 > 4 | 1.0s |
| 3 | Climax | BOSS 战 / 叙事高潮 | 0.3s |
| 4 | Punishment | 失误时叠加效果 | 0.1s |

### 3.3 章节音乐风格

| 章节 | 风格 | 核心乐器 | BPM |
|------|------|---------|:---:|
| 序章 | 极简钢琴 | 钢琴独奏 | 60 |
| 第一章 | 自然交响 | 木管、弦乐、竖琴 | 90 |
| 第二章 | 工业氛围 | 合成器、低音贝斯 | 120 |
| 终章 | 史诗交响 | 全交响乐团 | 80→140 |

## 5. "静默" 音效设计

### 5.1 静默的声音 (矛盾的设计)

静默不是"没有声音"，而是"吞噬声音"。

**技术实现**:
- 当静默靠近时，应用**动态 Low-Pass Filter**
- 截止频率随距离变化: `CutoffHz = 20000 - (20000 * (1 - Distance/MaxDistance))`
- 同时增加**Reverb Wetness**，营造空洞感

### 5.2 静默音效列表

| 音效 | 描述 |
|------|------|
| `S_Silence_Creep` | 静默蔓延的轻微"嘶嘶"声 |
| `S_Silence_Consume` | 吞噬声音的低频隆隆声 |
| `S_Silence_Heartbeat` | 玩家心跳声（当所有其他声音被吞噬时） |

## 7. 终章：交响乐设计

### 7.1 音乐阶段演变

```
时间线:

Phase 1 (0:00 - 2:00)
│ 乐器: 钢琴独奏
│ 情感: 孤独、脆弱
│ 动机: 简单的三音动机 (C-E-G)
▼

Phase 2 (2:00 - 5:00)
│ 乐器: +大提琴
│ 情感: 对话、支持
│ 动机: 大提琴回应钢琴
▼

Phase 3 (5:00 - 8:00)
│ 乐器: +木管、法国号
│ 情感: 希望、力量
│ 动机: 主题变奏
▼

Phase 4 (8:00 - 10:00)
│ 乐器: 全交响乐团
│ 情感: 悲壮、升华
│ 动机: 完整主题，加入合唱
▼

Climax (10:00+)
│ 乐器: 全部 + 鲸鱼歌声
│ 情感: 超越、重生
│ 动机: 鲸鱼长鸣作为最终音符
```

### 7.2 鲸鱼长鸣 (The Whale's Song)

**技术规格**:
- 频率: 20Hz - 2000Hz (鲸鱼真实频率范围)
- 持续时间: 15秒
- 空间化: 从鲸鱼位置向全局扩散
- 混响: 无限延长，渐隐

## 8. 音频资产规范

### 8.1 命名约定

```
S_[类型]_[来源]_[变体]

示例:
S_Music_Forest_Layer1
S_SFX_Lung_SteamPerfect
S_Ambient_Ocean_Deep
S_Judge_Perfect_Forest
```

### 8.2 技术规格

| 属性 | 规格 |
|------|------|
| 格式 | WAV (源文件), OGG (运行时) |
| 采样率 | 48kHz |
| 位深 | 24-bit (源), 16-bit (运行时) |
| 声道 | 立体声 (音乐), 单声道 (SFX) |
