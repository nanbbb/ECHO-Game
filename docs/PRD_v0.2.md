## 1. 产品定义

### 1.1 核心概念 (High Concept)

**"Rhythm is Reality."** (节奏即现实)

玩家扮演"调律者"埃利安——世界上最后一个拥有"流动时间"的人。世界因"大石化"而陷入永恒静止，只有音乐能驱动时间重新流动。玩家通过精准的节奏演奏，逐步唤醒石化的世界，最终用生命换取星球的重生。

### 1.2 世界观

| 概念 | 描述 |
|------|------|
| **大石化** | 时间维度的冻结，所有生物和自然现象都凝固在最后一刻 |
| **静默** | 石化的元凶/现象，表现为吞噬声音的黑色油泥 |
| **调律者** | 能够维持局部时间流动的人，装备"共鸣肺" |
| **共鸣肺** | 管风琴+外骨骼融合体，是玩家的"第二心脏" |

### 1.3 目标受众

- 追求极致视听体验的单机玩家（《Hellblade》、《Death Stranding》受众）
- 寻求沉浸感的硬核音游玩家
- 喜爱叙事驱动游戏的玩家
- 对 UE5 视觉技术感兴趣的玩家

### 1.4 独特卖点 (USP)

| 特性 | 描述 |
|------|------|
| **叙事化节奏** | 判定点是场景中的真实物体，非下落式轨道 |
| **动态世界** | Nanite/Lumen 驱动的实时石化/复苏效果 |
| **情感深度** | 以生命为代价的救赎主题 |
| **电影流** | Sequencer 编排的一镜到底体验 |

## 2. 核心玩法

### 2.1 基础循环

```
环境预警 → 判定点呈现 → 玩家输入 → 世界响应
    │           │            │           │
    ▼           ▼            ▼           ▼
 物体颤动    视觉高亮      按键时机    复苏/石化
```

### 2.2 操作模式

| 操作类型 | PC 键位 | 手柄 | 用途 |
|---------|---------|------|------|
| **点击 (Tap)** | S/D/K/L | □×△○ | 点亮灯光、唤醒物体 |
| **长按 (Hold)** | 长按上述键 | 持续按住 | 融化海水、维持能量 |
| **连打 (Mash)** | 快速连按 | 快速连按 | 终章高潮、挣脱束缚 |

### 2.3 判定系统

| 等级 | 窗口 | 生命力影响 | 视觉反馈 |
|------|:----:|:---------:|:---------|
| **Perfect** | <80ms | +8% | 屏幕闪光 + 复苏脉冲 |
| **Good** | 80-150ms | +3% | 正常脉冲 |
| **Miss (按错)** | >150ms | -2% | 无效果 |
| **Miss (不按)** | 节拍遗漏 | -3% | 无效果 |

### 2.4 生命系统

**概念**: 生命力 (LifeForce) 通过环境颜色变化表达。

| 生命力 | 视觉表现 | 游戏状态 |
|:------:|:---------:|:---------:|
| 100% | 明亮鲜艳 (绿色) | 正常 |
| 50% | 中等色彩 | 正常 |
| 20% | 去饱和灰暗 | 警告 |
| 5% | 几乎黑白 | 死亡 |

- **自然衰减**: 1.5%/秒
- **死亡触发**: LifeForce <= 5%

## 4. 技术需求

### 4.1 核心系统

| 系统 | 技术 | 优先级 |
|------|------|:------:|
| 音频时钟 | Quartz Subsystem | P0 |
| 复苏材质 | MPC + MF_RevivalLogic | P0 |
| 动态音乐 | 分层音轨 + Submix | P1 |
| 共鸣肺 | Niagara + 动画 | P1 |

### 4.2 视觉规格

| 技术 | 规格 |
|------|------|
| **Nanite** | 全场景 Nanite 网格 |
| **Lumen** | 硬件光追 (高画质) / 软件光追 (性能) |
| **分辨率** | 1440p@60fps (最低) / 4K@60fps (目标) |
| **光追反射** | Lumen Reflections |

### 4.3 性能目标

| 平台 | 帧率 | 分辨率 | 光追 |
|------|:----:|:------:|:----:|
| PC (High) | 60-120 | 4K | 硬件 |
| PC (Med) | 60 | 1440p | 软件 |
| PS5 | 60 | 1440p 或 4K | 软件 |

## 7. 无障碍设计

| 选项 | 描述 |
|------|------|
| **一键模式** | 所有输入简化为任意键 |
| **加宽判定** | 将 Perfect 窗口扩大到 ±60ms |
| **高对比度** | 判定物体高亮为明黄色 |
| **色盲模式** | 调整色板适应色盲用户 |
| **剧情模式** | 生命值不会归零 |
