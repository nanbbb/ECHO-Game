## 1. 角色美术

### 1.1 主角：埃利安 (Elian)

#### 概念设计要点

| 部位 | 设计要求 | 技术实现 |
|------|---------|---------|
| **面罩** | 铜质防毒面具，呼吸时有蒸汽 | SubSurface 材质 + Niagara 蒸汽 |
| **风衣** | 破旧厚重，布料模拟 | Cloth Physics |
| **共鸣肺** | 管风琴+外骨骼混合体 | 可分离组件，独立动画 |

#### "共鸣肺" 详细设计

```
                    [排气管阵列]
                   ╱ ╱ ╱ ╱ ╱ ╱
                  ╱ ╱ ╱ ╱ ╱ ╱
            ┌────────────────────┐
            │    [仪表盘]        │  ← 生命值显示
            │  ┌──────────────┐  │
            │  │              │  │
            │  │   [风箱]     │  │  ← 随呼吸膨胀收缩
            │  │              │  │
            │  └──────────────┘  │
            │  [肩部支架]        │  ← 外骨骼结构
            └────────────────────┘
                    ‖
            [呼吸管连接面罩]
```

**LOD 规划**:
| LOD | 面数 | 距离 | 说明 |
|:---:|:----:|:----:|------|
| 0 | 50K | < 5m | 完整细节，布料模拟 |
| 1 | 20K | 5-15m | 简化机械细节 |
| 2 | 5K | > 15m | 基础形态 |

### 1.2 反派：熵 (The Entropy)

**材质需求**:
- 完全黑色，不反射任何光
- 边缘有热浪扭曲效果 (Post Process)
- 半透明，可看到微弱的内部"漩涡"

**Shader 关键参数**:
```
Base Color: (0, 0, 0)
Opacity: 0.95
Refraction: 1.5
Emissive: 负值 (吸光效果)
Custom: 边缘扭曲强度
```

## 3. 材质系统

### 3.1 复苏材质层级

```
M_Master_Revival (主材质)
├── MI_Env_Organic  (有机物: 植物、生物)
│   ├── MI_Tree_Oak
│   ├── MI_Flower_Rose
│   └── MI_Mushroom
├── MI_Env_Mineral  (矿物: 石头、金属)
│   ├── MI_Rock_Canyon
│   └── MI_Metal_Bronze
├── MI_Env_Liquid   (液体: 水、海洋)
│   └── MI_Water_Ocean
└── MI_Char_*       (角色专用)
    ├── MI_Elian_Skin
    └── MI_Elian_Lung
```

### 3.2 顶点色规范

| 通道 | 用途 | 取值范围 |
|:----:|------|:--------:|
| **R** | WPO 权重 (风动强度) | 0-1 |
| **G** | 复苏遮罩 | 0=永久石化, 1=可复苏 |
| **B** | AO/Dirt 混合 | 0-1 |
| **A** | 自发光权重 | 0-1 |

### 3.3 特殊材质

#### 琥珀色海水材质

```
需求:
- 高透明度，可见内部物体
- 琥珀色调，类似树脂
- 折射效果
- 表面有微弱的光泽

技术实现:
- Translucent 混合模式
- Subsurface Scattering
- 折射 Index: 1.45 (接近真实琥珀)
- 表面 Roughness: 0.1
```

#### 古树心脏材质

```
需求:
- 心脏形状的凹陷处
- 微弱的脉动光效
- 石化→复苏过渡

技术实现:
- 自发光与游戏状态绑定
- 脉动使用 Sin(Time) 驱动
- 复苏遮罩应用
```

## 5. 模型制作规范

### 5.1 Nanite 资产
- **轴心点**: 物体底部中心
- **UV**: 必须展开 Lightmap UV
- **碰撞**: 使用 UCX_ 前缀简化碰撞体

### 5.2 双状态资产 (石化/复苏)

对于需要"变形"的物体:
1. **State A (Stone)**: 闭合造型，模糊细节
2. **State B (Revived)**: 绽放造型，高细节
3. **VFX (Debris)**: 碎块，用于过渡效果

```
工作流:
                    ┌─────────────┐
                    │ Zbrush 雕刻 │
                    └──────┬──────┘
                           │
              ┌────────────┼────────────┐
              ▼            ▼            ▼
        [State A]    [State B]    [Debris]
        石化版本      复苏版本      碎片
              │            │            │
              ▼            ▼            ▼
        [Retopo]     [Retopo]    [Houdini]
              │            │            │
              └────────────┼────────────┘
                           ▼
                     [UE5 导入]
```

## 6. 性能优化

### 6.1 实例化策略

| 资产类型 | 策略 |
|---------|------|
| 树木 | Hierarchical Instanced Static Mesh |
| 石头 | Packed Level Actor |
| 悬浮物(雨滴/树叶) | Niagara GPU 粒子 |

### 6.2 LOD 策略

| 距离 | 设置 |
|:----:|------|
| < 50m | LOD0 + 完整 WPO |
| 50-200m | LOD1 + 简化 WPO |
| > 200m | LOD2 + 无 WPO |
